# Sources and evidence register

Research checked 2026-11-02. Primary documentation and repository files support the survey and current-contract inventory. Architectural choices, estimates and SLO proposals are this project's recommendations. Feature support depends on edition, release and configuration; no upstream benchmark or certification is inherited by Falcone.
